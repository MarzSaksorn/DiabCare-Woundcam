# เช็กลิสต์ประเมินประเภทแผล

## วัตถุประสงค์

เอกสารนี้อธิบายหมวดหมู่แผลที่ใช้โดยโมเดล DiabCare WoundCam เพื่อช่วยตรวจภาพ จัดทำป้ายกำกับข้อมูล และสนับสนุนการตัดสินใจเบื้องต้น

เอกสารนี้ **ไม่ใช่การวินิจฉัยหรือแนวทางการรักษา** แพทย์หรือบุคลากรทางการแพทย์ต้องเป็นผู้ยืนยันประเภทแผล การติดเชื้อ ความลึก การไหลเวียนเลือด และแผนการรักษา

เว็บไซต์ต้องแสดงผลจากโมเดลสองชุดแยกกัน:

1. โมเดลตรวจจับระบุบริเวณที่มองเห็นและวาดกรอบรอบบริเวณนั้น
2. โมเดลจำแนก AZH กำหนดหมวดหมู่ระดับภาพให้กับภาพที่ถูกครอบจากบริเวณนั้น

ห้ามแปลงป้ายกำกับของโมเดลหนึ่งเป็นอีกโมเดลโดยอัตโนมัติ เช่น `dfu_ulcer` มีความเกี่ยวข้องกับ `D` แต่ไม่ใช่ป้ายกำกับเดียวกัน

## เช็กลิสต์ตรวจภาพทั่วไป

สำหรับทุกภาพหรือทุกบริเวณที่โมเดลตรวจพบ:

- [ ] บันทึกป้ายกำกับของโมเดล
- [ ] บันทึกตำแหน่งบนร่างกาย
- [ ] ระบุว่าเป็นแผลเปิด ผิวหนังปกติ หรือภาพพื้นหลัง
- [ ] ภาพมีคุณภาพเพียงพอสำหรับการตรวจหรือไม่
- [ ] บันทึกขนาดแผลโดยประมาณเมื่อมองเห็นได้
- [ ] บันทึกลักษณะพื้นแผล:
  - [ ] เนื้อเยื่อแกรนูเลชัน
  - [ ] เนื้อเยื่อสีเหลืองหรือสลัฟ
  - [ ] เนื้อตายหรือเอสชาร์
  - [ ] เห็นไขมัน เส้นเอ็น ข้อต่อ หรือกระดูก
- [ ] บันทึกลักษณะสารคัดหลั่ง:
  - [ ] ไม่มี
  - [ ] ใสหรือซีรัม
  - [ ] มีเลือด
  - [ ] ข้นสีเหลืองหรือสีเขียว
  - [ ] มีกลิ่นเหม็น
- [ ] บันทึกผิวหนังรอบแผล:
  - [ ] แดงหรือมีสีผิวเปลี่ยนไป
  - [ ] บวม
  - [ ] อุ่นกว่าปกติ
  - [ ] ผิวเปื่อยชื้น
  - [ ] มีหนังหนาด้านหรือคอลลัส
  - [ ] ผิวหนังแตกหรือถลอก
- [ ] ตรวจสัญญาณเตือนการติดเชื้อ
- [ ] ส่งต่อประเมินทางคลินิกหากสงสัยการไหลเวียนเลือดไม่ดีหรือภาวะขาดเลือด
- [ ] ต้องให้บุคลากรทางการแพทย์ตรวจทาน

## ป้ายกำกับจากโมเดลตรวจจับ

### `dfu_ulcer` — แผลเท้าเบาหวาน

- [ ] เห็นรอยโรคหรือแผลเปิดที่เท้า
- [ ] มีข้อมูลว่าเป็นเบาหวานหรือมีบริบทเกี่ยวกับภาวะแทรกซ้อนที่เท้าจากเบาหวาน
- [ ] บันทึกตำแหน่ง: ฝ่าเท้า นิ้วเท้า ส้นเท้า ด้านข้างเท้า หรือบริเวณรับแรงกด
- [ ] มีคอลลัสหรือผิวหนังหนาใกล้แผล
- [ ] พิจารณาภาวะเส้นประสาทเสื่อมหรือความรู้สึกลดลง
- [ ] พิจารณาการไหลเวียนเลือด ภาวะขาดเลือด และโรคหลอดเลือด
- [ ] ตรวจสัญญาณการติดเชื้อ
- [ ] ประเมินความลึกและโครงสร้างที่อาจเปิดออก
- [ ] ต้องใช้ประวัติผู้ป่วยและการตรวจทางคลินิกก่อนยืนยัน

แผลเท้าเบาหวานคือการสูญเสียความต่อเนื่องของผิวหนังที่เท้าซึ่งเกี่ยวข้องกับโรคเบาหวาน โดยภาวะเส้นประสาทเสื่อมและโรคหลอดเลือดส่วนปลายเป็นปัจจัยเสี่ยงที่พบบ่อย ป้ายกำกับจากภาพเพียงอย่างเดียวไม่สามารถยืนยันการวินิจฉัยได้

### `infected_wound` — แผลติดเชื้อ

- [ ] มีรอยแดงหรือสีผิวรอบแผลเปลี่ยนไปมากขึ้น
- [ ] มีอาการบวมหรือเนื้อเยื่อแข็งตัว
- [ ] บริเวณแผลอุ่นขึ้น
- [ ] กดเจ็บหรือปวดมากขึ้น
- [ ] มีหนองหรือสารคัดหลั่งเป็นหนอง
- [ ] มีกลิ่นเหม็น
- [ ] แผลใหญ่ขึ้นหรือลึกขึ้น
- [ ] มีไข้หรือรู้สึกไม่สบาย
- [ ] พิจารณาการลุกลามไปยังเนื้อเยื่อลึกหรือกระดูก
- [ ] ให้บุคลากรทางการแพทย์ประเมินความรุนแรงของการติดเชื้อ

ภาพถ่ายเพียงอย่างเดียวไม่สามารถยืนยันหรือจัดระดับการติดเชื้อได้ แนวทาง IWGDF/IDSA ใช้อาการอักเสบทางคลินิกและอาการทั่วร่างกายประกอบการประเมิน

### `necrotic_wound` — แผลที่มีเนื้อตาย

- [ ] เห็นเนื้อเยื่อสีดำ น้ำตาล เทา หรือสีคล้ำ
- [ ] พิจารณาว่าเป็นเอสชาร์แห้งแข็งหรือเนื้อตายเปียกนิ่ม
- [ ] บันทึกว่ามีสลัฟบังพื้นแผลหรือไม่
- [ ] ห้ามสรุปความลึกของแผลจากภาพเพียงอย่างเดียว
- [ ] ตรวจกลิ่นและสารคัดหลั่ง
- [ ] ตรวจรอยแดง ความอุ่น และอาการบวมรอบแผล
- [ ] ให้บุคลากรทางการแพทย์ประเมินการไหลเวียนเลือดและความมีชีวิตของเนื้อเยื่อ
- [ ] การประเมินพื้นแผลหรือการตัดเนื้อตายต้องทำโดยผู้เชี่ยวชาญ

สีคล้ำเพียงอย่างเดียวไม่ได้ยืนยันว่าเป็นเนื้อตาย ป้ายกำกับนี้ควรใช้เพื่อส่งต่อให้ตรวจทาน ไม่ใช่ใช้ตัดสินวิธีรักษา

### `callus_corn` — หนังด้านหรือตาปลา

- [ ] เห็นผิวหนังหนาหรือแข็ง
- [ ] ระบุจุดที่มีแรงกดเฉพาะที่
- [ ] มีลักษณะเหลืองหรือผิวหนังหนาผิดปกติ
- [ ] พิจารณารอยโรคเป็นวงกลมหรืออยู่เป็นจุด
- [ ] บันทึกอาการปวดหรือแรงกด
- [ ] พิจารณาว่าอาจมีแผลซ่อนอยู่ใต้คอลลัส
- [ ] ตรวจรองเท้าและแรงกดซ้ำ ๆ
- [ ] ห้ามจัดเป็นแผลเปิดโดยอัตโนมัติ

### `normal_foot` — เท้าที่มองเห็นว่าปกติ

- [ ] ไม่เห็นแผลเปิด
- [ ] ผิวหนังดูต่อเนื่องและไม่แตก
- [ ] ไม่เห็นสารคัดหลั่งชัดเจน
- [ ] ไม่เห็นอาการบวมมาก
- [ ] ไม่เห็นสีผิวผิดปกติชัดเจน
- [ ] ไม่เห็นแผล คอลลัส หรือตาปลาที่ต้องส่งต่อโดยทันที
- [ ] ภาพมีคุณภาพเพียงพอ

ผลลัพธ์นี้หมายถึงไม่พบความผิดปกติที่มองเห็นได้จากภาพ ไม่ได้ยืนยันว่าการไหลเวียนเลือด ความรู้สึก หรือสุขภาพเท้าปกติทั้งหมด

## ป้ายกำกับจากโมเดลจำแนก AZH

### `BG` — พื้นหลัง

- [ ] ไม่เห็นบริเวณผิวหนังหรือแผลที่ชัดเจน
- [ ] ภาพอาจเป็นพื้นหลัง เสื้อผ้า อุปกรณ์ หรือสิ่งที่ไม่เกี่ยวข้อง
- [ ] ห้ามตีความว่าเป็นประเภทแผล
- [ ] พิจารณาถ่ายใหม่ จัดกรอบใหม่ หรือครอบภาพให้เห็นบริเวณผิวหนัง

### `N` — ผิวหนังปกติ

- [ ] มองเห็นผิวหนัง
- [ ] ไม่เห็นแผลเปิดชัดเจน
- [ ] ไม่เห็นแผลหลุมหรือแผลเปื่อยชัดเจน
- [ ] ไม่เห็นแผลผ่าตัดชัดเจน
- [ ] ไม่เห็นรูปแบบที่ชัดเจนของแผลกดทับ
- [ ] ไม่เห็นรูปแบบที่ชัดเจนของแผลหลอดเลือดดำ

`N` หมายถึงผิวหนังที่ดูปกติภายในชุดป้ายกำกับของโมเดล ไม่ใช่การยืนยันทางคลินิกว่าผิวหนังหรือเท้าปลอดภัยทั้งหมด

### `D` — แผลจากเบาหวาน

- [ ] มองเห็นแผล
- [ ] มีบริบทว่าเกี่ยวข้องกับโรคเบาหวาน
- [ ] ตรวจตำแหน่งเท้าและบริเวณรับแรงกด
- [ ] พิจารณาคอลลัสและภาวะเส้นประสาทเสื่อม
- [ ] ตรวจสัญญาณการติดเชื้อ
- [ ] พิจารณาการไหลเวียนเลือดและความเสี่ยงภาวะขาดเลือด
- [ ] ยืนยันด้วยประวัติผู้ป่วยและการตรวจทางคลินิก

`D` และ `dfu_ulcer` เป็นแนวคิดที่เกี่ยวข้องกัน แต่ไม่ใช่ป้ายกำกับเดียวกัน ต้องแสดงผลจากโมเดลทั้งสองแยกกัน

### `P` — แผลกดทับ

- [ ] อยู่เหนือปุ่มกระดูกหรือบริเวณที่มีแรงกดซ้ำ ๆ
- [ ] พิจารณาส้นเท้า ข้อเท้า สะโพก ข้อศอก กระเบนเหน็บ หรือจุดรับแรงกดอื่น
- [ ] ประเมินสีผิวที่เปลี่ยนและไม่จางลงเมื่อกด
- [ ] ประเมินความอุ่น ความแข็ง ความนุ่มยวบ หรือความเจ็บปวด
- [ ] บันทึกว่ามีตุ่มพองหรือแผลเปิดหรือไม่
- [ ] ตรวจความเสี่ยงจากการเคลื่อนไหวจำกัด แรงเสียดสี แรงเฉือน และความชื้น
- [ ] ส่งต่อประเมินหากสงสัยว่าเนื้อเยื่อลึกได้รับผลกระทบ

แผลกดทับอาจเริ่มจากสีผิวเปลี่ยนถาวรและพัฒนาเป็นตุ่มพองหรือแผลลึกได้

### `S` — แผลผ่าตัด

- [ ] มองเห็นแผลผ่าตัดหรือบริเวณที่ทำหัตถการ
- [ ] ขอบแผลปิดสนิท แยกออกบางส่วน หรือแยกออกทั้งหมด
- [ ] อาจเห็นไหมเย็บ ลวดเย็บ หรือผ้าปิดแผล
- [ ] ตรวจรอยแดงและอาการบวม
- [ ] ตรวจเลือดออกหรือสารคัดหลั่งที่เพิ่มขึ้น
- [ ] ตรวจสารคัดหลั่งข้นสีเหลืองหรือสีเขียว
- [ ] ตรวจกลิ่นผิดปกติ
- [ ] ตรวจว่าแผลใหญ่ขึ้นหรือลึกขึ้นหรือไม่
- [ ] ตรวจไข้หรืออาการปวดที่แย่ลง
- [ ] ติดต่อศัลยแพทย์หรือบุคลากรทางการแพทย์เมื่อพบสัญญาณเตือน

### `V` — แผลจากหลอดเลือดดำ

- [ ] อยู่บริเวณหน้าแข้งส่วนล่างหรือรอบข้อเท้า
- [ ] อาจมีอาการบวมของขาหรือข้อเท้า
- [ ] พิจารณาสีผิวและการเปลี่ยนแปลงของผิวจากโรคหลอดเลือดดำเรื้อรัง
- [ ] พิจารณาลักษณะแผลตื้นหรือขอบไม่เรียบ
- [ ] บันทึกสารคัดหลั่ง
- [ ] บันทึกอาการคัน ผิวลอก หรือผิวคล้ายผื่นเอ็กซีมา
- [ ] ตรวจสัญญาณการติดเชื้อ
- [ ] ประเมินการไหลเวียนเลือดแดงก่อนการรักษาด้วยแรงกด
- [ ] การรักษาด้วยแรงกดต้องอยู่ภายใต้การดูแลของบุคลากรที่ผ่านการฝึกอบรม

## รูปแบบการแสดงผลบนเว็บไซต์

สำหรับแต่ละบริเวณที่ตรวจพบ ให้แสดงผลแยกกันดังนี้:

```text
โมเดลตรวจจับ:
  dfu_ulcer · 82%

โมเดลจำแนก AZH:
  D · Diabetic wound · 67%

ความน่าจะเป็นจาก AZH:
  BG · Background · 3%
  D  · Diabetic wound · 67%
  N  · Normal skin · 4%
  P  · Pressure wound · 12%
  S  · Surgical wound · 5%
  V  · Venous wound · 9%

สถานะ:
  เป็นเพียงข้อเสนอแนะจากโมเดล
  ต้องให้บุคลากรทางการแพทย์ตรวจทาน
```

## ขอบเขตความปลอดภัย

โมเดลอาจช่วยตรวจภาพเบื้องต้นได้ แต่ต้องไม่ใช้ตัดสินโดยอัตโนมัติเรื่องการวินิจฉัย ระดับความรุนแรง ระยะของแผล การรักษา การตัดเนื้อตาย การใช้แรงกด ยาปฏิชีวนะ หรือการพยากรณ์การหายของแผล
